Questions fréquentes

Quels sont les délais de réponse à mes demandes ?

Nous nous efforçons de répondre à toutes les demandes dans un délai de 48 heures ouvrées. Pour les questions complexes nécessitant une expertise spécifique, le délai peut être étendu à 5 jours ouvrés maximum.

Comment suivre l'état de ma demande ?

Une fois votre demande soumise via le formulaire, vous recevrez un email de confirmation avec un numéro de référence. Vous pourrez utiliser ce numéro pour suivre l'état de votre demande dans la section "Suivi des demandes" après connexion à votre compte I-Prof.

À qui dois-je m'adresser pour une question spécifique sur ma carrière ?

Pour les questions relatives à votre carrière (avancement, promotion, etc.), nous vous recommandons de contacter directement votre gestionnaire via la messagerie I-Prof une fois connecté à votre espace personnel.

Comment récupérer mes identifiants perdus ?

Si vous avez perdu vos identifiants, vous pouvez utiliser la fonction "Mot de passe oublié" sur la page de connexion ou contacter directement le support technique de votre académie. Vous pouvez également vous connecter avec FranceConnect si vous disposez d'un compte.
