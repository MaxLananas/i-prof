Nouveau mot de passe

Veuillez fournir les informations permettant de vous identifier dans notre système.

Votre NUMEN ou votre adresse email académique (prenom.nom@ac-academie.fr)
Cette information est utilisée pour vérifier votre identité

Veuillez choisir une méthode pour recevoir votre code de vérification.

Méthode de vérification

Un code de vérification à 6 chiffres a été envoyé à l'adresse email/numéro de téléphone associé à votre compte.

Vous n'avez pas reçu le code ? Renvoyer le code

Veuillez créer un nouveau mot de passe pour votre compte I-Prof.

Votre mot de passe doit contenir au moins 12 caractères, incluant des majuscules, des minuscules, des chiffres et des caractères spéciaux.

Votre mot de passe a été réinitialisé avec succès !

Vous pouvez maintenant vous connecter à I-Prof avec votre nouvel identifiant.
